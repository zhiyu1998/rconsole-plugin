## 🌟 Características

- 📦 Listo para usar: solo `git clone` al directorio de `Yunzai` y está funcionando.
- 🚀 Velocidad extrema: optimizado para entornos de subprocesamiento único y múltiple. Los usuarios pueden integrarlo con `BBDown` o `Aria2`.
- 🤔 Enfoque multifacético: se ha optimizado tanto la visualización de contenido en baja calidad como la de alta calidad.
- 💪 Alta robustez: con un largo historial de desarrollo open-source, una gran base de usuarios, resolución rápida de `bugs` y ejecución estable.
- 📄 Documentación completa: comentarios en el código abundantes, facilitando la depuración y el desarrollo.

## 📔 Instalación /es

1. Descarga del plugin
```shell
# China
git clone https://gitee.com/kyrzy0416/rconsole-plugin.git ./plugins/rconsole-plugin/
# Internacional
git clone https://github.com/zhiyu1998/rconsole-plugin.git ./plugins/rconsole-plugin/
```

2. En el directorio `Yunzai-Bot / Miao-Yunzai`, instala `axios` (0.27.2), `tunnel` (herramienta de proxy), `qrcode` (gestor de códigos QR), `p-queue` (cola de descarga de alto rendimiento), `ws` (para Lagrange) y `openai` (para análisis de imagen).


```shell
pnpm i --filter=rconsole-plugin
```


3. Para usar la función de `análisis de video`, debes instalar `ffmpeg` [Se recomienda Ubuntu]
```shell
# Ubuntu
sudo apt-get install ffmpeg
# Otras distribuciones de Linux (recomendación de la comunidad): https://gitee.com/baihu433/ffmpeg
# Windows: https://www.jianshu.com/p/5015a477de3c
```

Consulta la documentación oficial para más ideas.
